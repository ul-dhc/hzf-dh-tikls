# HZF digitālo humanitāro zinātņu aktivitāšu tīkls

Interaktīva tīklu vizualizācija digitālo humanitāro zinātņu aktivitātēm Latvijas
Universitātes Humanitāro zinātņu fakultātē - projekti, digitālie resursi,
studiju kursi un citas aktivitātes, sagrupētas pa HZF nodaļām un DH tematiem.

**Tīmekļa vietne:** https://ul-dhc.github.io/hzf-dh-tikls/

- **Punkti:** fakultātes nodaļas, aktivitātes pēc tipa, DH temati
- **Savienojumi:** nepārtrauktā līnija savieno aktivitātes, nodaļas un tēmas,
  raustītā līnija savieno resursus un kursus ar konkrētu projektu
- Sānu paneļos var filtrēt skatu pēc aktivitātes tipiem vai nodaļām.
